# Run the game in Chrome

1. Install Node.js 22 LTS if it is not already installed.
2. Double-click `start-game.bat`. The first run downloads the locked game packages and can take a few minutes.
3. When the terminal shows a `Local` address (usually `http://127.0.0.1:5173/`), open it in Google Chrome.
4. Keep the terminal window open while you play. Press **Ctrl+C** in it to stop the local game.

The game runs on your computer. Career wallet, distance, trips and owned paint are saved in that browser's local storage. The garage wallet is separate from the existing cash carried during a drive.

## New career features

- Start with **₹2,500** in the saved garage wallet.
- Earn **₹100 per kilometre** driven in the truck.
- Buy and equip **Monsoon Jade** (₹900) and **Royal Indigo** (₹1,600) truck paint.
- The paint selection is applied when the next drive starts.

The garage is available from the coin wallet in the in-game HUD or from the pause menu's **Garage** tab.
